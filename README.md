# Supplement-Tracker

Mobile tracker to tick off daily supplements (Vitamin D3, K2, B-Komplex, Omega-3, Kreatin, Zink, Magnesium).

- `supplement-tracker.html` – source of the published claude.ai Artifact. It stores data in the artifact's `db` capability (`supplements` and `days` collections) and falls back to `localStorage` outside claude.ai.
- Live: https://claude.ai/artifact/2D69xVFGYiniKUEXtMgYPY

> **Jetzt in GainLog integriert:** Der Tracker lebt als Reiter „Supps" in [GainLog](https://github.com/Lennix142/gainlog) weiter (Supabase statt Artifact-Speicher, +10 XP wenn alles genommen ist). Die Startliste dort entspricht der Liste aus diesem Artifact.
